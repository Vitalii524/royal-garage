# Підтвердження власника Royal Garage

1. Узгодити початок перевірки з власником через уже відомий незалежний канал зв’язку. Зафіксувати окреме підтвердження, що власник просить адміністративну роль саме для особистого акаунта v429771@gmail.com.
2. Власник сам входить на royalgarage.com.ua під цим акаунтом. За потреби користується чинною процедурою відновлення пароля або підтвердження пошти. Пароль, коди та посилання для входу не передаються виконавцю або в чат.
3. Перевірити керування платформою через чинний підтверджений доступ власника до проєкту Render або репозиторію GitHub. Підтверджена адреса пошти сама по собі не є доказом володіння платформою.
4. До запису в робочу базу перевірити резервну копію пробним відновленням в ізольованій PostgreSQL. У відновленій копії перевірити пошук одного активного особистого акаунта за точною адресою та його незмінним ID.
5. Після підтвердження власника уповноважений оператор у транзакції фіксує попереднє значення ролі й призначає чинну роль admin лише цьому ID. Запис має змінити рівно один підтверджений активний акаунт. Зберегти запис про погодження й перевірку.
6. Власник повторно входить і відкриває чинну адмінпанель. Перевірити серверний доступ на дозволеній операції читання. Окремо перевірити відмову для звичайного користувача, власника бізнесу та RoyalAuto. Якщо доступ не підтверджено, відновити попередню роль за записом із кроку 5.
